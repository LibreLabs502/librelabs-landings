Qué es LibreLabs

Un pequeño laboratorio, no una corporación gigante

Construimos herramientas Open Source enfocadas en la accesibilidad, la autonomía y los pequeños negocios: tecnología sencilla, software útil y una comunidad alrededor.

Misión

Devolver el control de la tecnología a las personas que la usan, con software libre, sencillo y accesible.

Visión

Un ecosistema de herramientas abiertas que permita a personas y pequeños negocios usar tecnología sin depender de plataformas cerradas.

Metas

Publicar más proyectos, cerrar el roadmap de LibreDrop y sumar una comunidad que use, reporte y contribuya.

LibreLabs Cloud

¿Y qué es LibreLabs Cloud?

LibreLabs construye software libre. LibreLabs Cloud es la otra mitad: la capa de servicios administrados. Es el mismo software Open Source, ya montado y mantenido por el equipo, para quien prefiere no encargarse del servidor.

Diferencias entre LibreLabs (Open Source) y LibreLabs Cloud
  LibreLabs · Open Source LibreLabs Cloud
Qué es El laboratorio que crea el software libre. La capa de servicios administrados de LibreLabs.
Qué ofrece Proyectos Open Source (AGPLv3) y su código. El mismo software, ya instalado y mantenido.
Infraestructura La administrás vos (self-hosting). La administra LibreLabs por vos.
Precio El software es gratis. Servicio de pago · LibreDrop Cloud, Q100/mes.
Control Total: estudiás, modificás y ejecutás donde quieras. Tus datos siguen siendo tuyos, con el equipo al cuidado.

Open Source

Libre por diseño

Creemos en el software libre: podés estudiarlo, modificarlo, usarlo y contribuir. La transparencia no es un extra, es parte de cómo trabajamos.

  • ✓ Transparencia. Cualquiera ve qué hace el código y cómo se manejan los datos.
  • ✓ Estudiarlo y modificarlo. El código está abierto para aprender y adaptarlo.
  • ✓ Self-hosting. Podés ejecutar los proyectos en tu propia infraestructura.
  • ✓ Control de tus datos. No quedan encerrados en un sistema propietario.
